# Project plans

This directory records agreed implementation plans that span multiple changes.
Plans describe the intended result, the order of work, and the checks required
at each stage. They are not a substitute for the issue backlog: independently
actionable deferred bugs still belong under `backlog/issues/`.

## Active plans

- [Raspberry Pi deployment](raspberry-pi-deployment.md) — package the UI and API,
  run them reproducibly with Docker Compose, deploy them to a Raspberry Pi, and
  expose the application through Cloudflare Tunnel.
