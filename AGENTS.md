## Deferred issues

When you identify a non-blocking problem that the user wants to defer, create a
structured Markdown ticket under `backlog/issues/`. Do not implement a deferred
ticket unless the user explicitly requests it.

Follow the ticket format and naming rules in `backlog/README.md`. Include enough
context that a future agent can understand the problem without access to the
conversation where it was discovered. Record concrete evidence, relevant file
paths, and acceptance criteria whenever they are known. Do not invent missing
details; mark them as unknown or needing investigation.
